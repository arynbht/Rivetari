`factory metrics` shows where the tier 1 rules come from: from findings, stack defaults, or built in and written by hand. Banned patterns sourced from a finding count as from findings, and so do lint rules a finding's banned entry is covered by. Entering unattended now also needs 20 tier 1 rules without counting stack defaults, so from here only rules from findings move the count. `factory doctor` warns when the system temp folder holds 20,000 or more entries, which makes every local proof and judge run several times slower. `factory task status` lists a closed task as closed, including one closed before it was confirmed. The autonomy ledger re-renders its `ledger.md` when only the view changed (a formatter, say) and the signed record still verifies, and `.factory/` is left out of prettier so it isn't reformatted again.
